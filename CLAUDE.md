# Instrucciones para Claude

- Lee el `README.md`: contiene el estado, las decisiones tomadas y lo pendiente.
- Responde en español.
- El usuario define cada pantalla paso a paso. No construyas ni cambies nada que no haya pedido; si falta información, pregunta o propón y espera confirmación.
- Los diseños viven en el lienzo de Claude (artefacto de tipo Design) https://claude.ai/artifact/PePYNCrFDjppLXP556QkFy. Sus fuentes son los archivos de `bocetos/` (en el lienzo están bajo `project/`). Para cambiar una pantalla: lee el archivo del artefacto, edítalo y vuelve a publicarlo en esa misma URL.
- Sube a GitHub (`main`) solo cuando el usuario lo pida, copiando los archivos del lienzo a `bocetos/` y actualizando el README.
